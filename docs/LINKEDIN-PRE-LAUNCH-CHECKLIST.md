## Troubleshooting Guide

### Issue: Post didn't publish
- [ ] Check LinkedIn notifications for errors
- [ ] Verify text isn't being filtered (use LINKEDIN-QUICK-COPY-PASTE.md)
- [ ] Try again within 30 minutes
- [ ] Contact LinkedIn support if persistent

### Issue: No engagement in first 24 hours
- [ ] Expected for new account. Continue posting.
- [ ] Note post type for adjustment next week.
- [ ] Don't remove post.
- [ ] Ensure comments replied to from other posts.

### Issue: DM inquiry but sales can't reach prospect
- [ ] Check message content for contact info
- [ ] Reply immediately from company page
- [ ] Ask for email/phone in response

### Issue: LinkedIn interface slow/buggy
- [ ] Use desktop browser if on mobile
- [ ] Clear browser cache
- [ ] Try different browser
- [ ] Post within 30 mins of scheduled time (not earlier)

### Issue: Hashtags not showing proper reach
- [ ] Hashtags are pre-optimized; don't modify
- [ ] Reach grows over time as account builds authority
- [ ] Week 1-2 reach is expected to be low (new account)
