## 💰 PRICING STRUCTURE FOR HIGH-VALUE LEADS (>30K EUR)

### GLASS TYPE PRICING (2026 USA Market)

**TEMPERED GLASS (4mm - 12mm):**
- Cost per m²: €28-35 (material + fabrication)
- Standard markup: 120-150%
- Selling price: €60-90 per m²
- Typical project: 500-1000 m² = €30k-90k

**LAMINATED GLASS (6mm - 15mm, includes PVB):**
- Cost per m²: €35-50 (higher material cost)
- Standard markup: 110-140%
- Selling price: €75-120 per m²
- Typical project: 400-800 m² = €30k-96k

**CURVED GLASS (Custom bends, all types):**
- Base cost: €45-70 per m²
- Complexity surcharge: +30-80% (radius, volume)
- Standard markup: 100-130%
- Selling price: €95-180 per m² (premium for complexity)
- Typical project: 200-400 m² = €19k-72k

**CERAMIC-PRINTED GLASS (Custom designs, enamel fused):**
- Base cost: €60-100 per m²
- Design surcharge: +20-40% (custom colors/patterns)
- Standard markup: 90-120% (lower markup due to high cost)
- Selling price: €130-240 per m²
- Typical project: 100-300 m² = €13k-72k

### MARGIN TARGETS BY SEGMENT

| Segment | Project Size | Margin % | Example |
|---------|--------------|----------|---------|
| **Commercial RE** | €100k-500k | 40-50% | €200k project = €80k-100k gross margin |
| **Hospitality** | €50k-150k | 45-55% | €100k project = €45k-55k gross margin |
| **Healthcare** | €80k-300k | 45-55% | €150k project = €67k-82k gross margin |
| **Education** | €60k-250k | 40-50% | €120k project = €48k-60k gross margin |

### DISCOUNT STRUCTURE (Negotiation Guides)

```
SCENARIO 1: High volume (1000+ m²)
List price: €100 per m²
Volume discount: -5% = €95 per m²
Reasoning: Economies of scale in fabrication

SCENARIO 2: Multiple project framework (3+ projects/year)
List price: €100 per m²
Frame agreement discount: -8% = €92 per m²
Reasoning: Relationship lock-in

SCENARIO 3: Expedited delivery (2-3 week compression)
List price: €100 per m²
Rush premium: +15% = €115 per m²
Reasoning: Production schedule disruption, overtime

SCENARIO 4: Specialty finishes (ceramic, custom coating)
List price: €150 per m²
Finish premium: Already included
Reasoning: R&D, custom color mixing, oven time
```

**Negotiation Floor (NEVER GO BELOW):**
- Minimum selling price: €55/m² (for highest volume deals, 1000+ m²)
- Minimum margin: 25% (only in extreme situations for market entry)
- Typical floor: €65-80/m² with 35-40% margin
