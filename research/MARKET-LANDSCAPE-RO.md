## 5. Standarde feroviare obligatorii RO

### Standarde EN/UE
| Standard | Scop | Emitent |
|---|---|---|
| **EN 15152:2019+A1:2023** | Parbrize trenuri (high-speed, heavy, light, metrou, **tramvai**). Test impact tip + rutiniere + abraziune + balistic | CEN |
| **EN 14179** | Sticlă laminată siguranță | CEN |
| **EN 12150** | Sticlă călită termic | CEN |
| **EN 12600** | Test impact pendular | CEN |
| **EN 13501-1** | Clasificare comportament la foc (obligatoriu cabină + interior) | CEN |
| **UIC R 010** | Recomandări UIC geamuri material rulant călători | UIC |
| **TSI LOC&PAS Reg. UE 1302/2014** | Interoperabilitate locomotive + material rulant pasageri pe rețea UE. Obligatoriu TEN-T. | Comisia Europeană / ERA |

### Autorități RO
| Autoritate | Rol |
|---|---|
| **AFER** (Autoritatea Feroviară Română) | Emite **omologarea tehnică** produse critice feroviare (inclusiv geamuri). **Fără AFER ATR, NU vinzi în RO.** Procedura prin „Norma omologare tehnică produse/servicii feroviare" (2000+actualizări). Cere: doc tehnică producător, certificate EN/TSI, teste validare lab agrement AFER, audit fabricant. Timeline: 6-12 luni. |
| **ASFR** (Autoritatea Siguranța Feroviară RO) | Autorizare introducere pe piață vehicule. Acordă AVV (Autorizație Punere în Funcțiune). |
| **ATR / AFV** | Aviz Tehnic Realizare — emis AFER pentru produse înglobate vehicule. Condiționează prezența pe lista furnizori agreați. |

### Certificare industrie (critical pe OEM)
| Standard | De ce |
|---|---|
| **IRIS / ISO/TS 22163** (UNIFE) | Echivalent IATF 16949 din auto. **Fără IRIS, nu intri pe lista furnizori Alstom/Siemens/Stadler/CAF/Hitachi.** Audit certificator extern (TÜV, DEKRA, Bureau Veritas) |
| ISO 9001 / 14001 / 45001 | Baseline calitate/mediu/SSM |
| REACH / RoHS / CE | Substanțe + marcaj construcție |

## 6. Canale procurement RO

- **SEAP / e-licitatie.ro** — toate achizițiile publice CFR/STB/operatori urbani municipali
- **licitatiapublica.ro** — agregat cumpărări directe (sub prag)
- **Negocieri directe OEM** — Astra, Softronic, Remarul, Electroputere VFU
- **Frame contracts ARF** (Autoritatea pentru Reformă Feroviară) — material rulant nou PNRR

Observație din .ods: **CFR cumpără fragmentat** la nivel sucursală regională (8 sucursale operaționale), cantități mici, multipli furnizori → strategie VAGOGLASS = consolidare pe regiune.
