## 🖥️ DELEGARE 3: @design-interaction → INTERACTIVE ELEMENTS
**Who:** Interaction Designer / Prototyper
**Deadline:** Week 2 (build interactive prototype)
**Specifications:**

### Glass Selector Tool (MVP Phase 1):
```
User Flow:
1. User selects Glass Type (Tempered, Laminated, Curved, Ceramic-Printed)
2. User selects Application (Facade, Interior, Cleanroom, etc.)
3. User selects Performance Need (Thermal, Acoustic, Impact, Decorative)
4. Tool displays:
   - Visual example (animated if possible)
   - Key specifications
   - Lead time (4-6 weeks)
   - Pricing range
   - "Get Quote" CTA → Contact form pre-filled with selections
```

**Specifications:**

- [ ] Mobile-responsive layout

### Case Study Carousel (Interactive):
