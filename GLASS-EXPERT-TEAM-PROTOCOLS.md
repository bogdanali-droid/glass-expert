### PROTOCOL 3: CRISIS/BLOCKER ESCALATION
**Severity Levels:**

```
🔴 P0 (CRITICAL) — Escalate IMMEDIATELY
- Website down / form broken
- Zero leads generated (after 5 days)
- Major design/content issue blocking dev
- Client emergency
Action: Notify @Glass via Slack (urgent) + @ana same day

🟡 P1 (HIGH) — Escalate within 24 hours
- <3 leads/week
- <5% email response rate
- Design delays affecting dev
- Technical blockers (dependency)
Action: Report in next standup + daily update to @Glass

🟢 P2 (MEDIUM) — Report in weekly
- Content tweaks needed
- Design refinements
- Process improvements
- Minor delays
Action: Include in weekly report
```

**Escalation Chain:**
```
Agent → @Glass (immediate) → @ana (if decision needed) → Bogdan (if strategic)
```
